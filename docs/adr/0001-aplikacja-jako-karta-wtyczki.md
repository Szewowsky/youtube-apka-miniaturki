# Aplikacja jako karta Wtyczki, nie osobny program

Robert chciał "wtyczkę + appkę". Aplikację budujemy jako pełnoekranową kartę tej samej Wtyczki, a nie jako osobny program na macOS: jedna instalacja, jeden kod, brak ostrzeżeń macOS o programach spoza App Store i brak drugiego narzędzia do utrzymania. Koszt: Aplikacja działa tylko przy otwartej przeglądarce Chromium.

## Considered Options

- **Osobny program na Maca** - odrzucony: podwaja pracę i utrzymanie, a jedyna przewaga (działanie bez przeglądarki) nie jest Robertowi potrzebna.
